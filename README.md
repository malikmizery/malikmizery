### About me ✨
- 🚀 I build modern web apps and APIs with ASP.NET Core and Blazor
- 🧭 Architecture: I use Vertical Slice Architecture for simplicity; I know Clean Architecture too, but I mostly work solo so VSA fits me better
- 🪟 I spent a long time with WinForms and also Blazor Hybrid using WinForms
- 📊 Most apps I built are for accounting systems
- 🌱 Always learning and improving

---

### What I do 🧑‍💻
- 🌐 Web apps: ASP.NET Core (MVC / Razor Pages), Blazor (Server/WebAssembly), Blazor Web App (Static SSR)
- 🔌 APIs: REST APIs with ASP.NET Core
- 🗄️ Data: EF Core + SQL Server (most common), SQLite, MySQL, PostgreSQL
- 🖥️ Desktop: WinForms and Blazor Hybrid (WinForms host)
- 🧪 Testing and debugging for stable apps
- ⚙️ CI/CD and deployments when needed
